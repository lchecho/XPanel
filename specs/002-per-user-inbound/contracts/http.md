# Contract: HTTP 界面（每用户专属入站增量）

本文件只描述相对 `specs/001-xray-user-management/contracts/http.md` 的变化。会话、CSRF、
`_request_id` 幂等、`_version` 乐观并发、PRG、错误渲染与无脚本可用性规则全部不变。

## 入站模板（原访问配置）

| 路由 | 变化 |
|---|---|
| `GET /templates`、`GET /templates/new`、`POST /templates` | 由 `/profiles` 更名 |
| 表单字段 | **新增** `listen_address`、`port_pool_start`、`port_pool_end`；**移除** `server_key`、`bootstrap_statistics_id`、`public_port` |

- 面板不再要求管理员输入服务端密钥；页面 MUST 说明每条专属入站的密钥由面板生成（FR-004）。
- 端口池校验：`1024 ≤ start ≤ end ≤ 65535`，字段级错误提示；容量为闭区间长度。
- 缩小端口池导致既有分配落在池外时，保存 MUST 成功，详情页 MUST 标识这些端口位于池外。

## 用户

| 路由 | 变化 |
|---|---|
| `POST /users` | 表单新增可选 `port`；留空表示由面板自动分配 |
| `GET /users` | 列表新增“端口”列，支持按端口搜索（FR-014） |
| `GET /users/{id}` | 详情新增端口、入站标签、监听状态（监听中 / 未监听 / 待同步） |
| `GET /users/{id}/connection` | 连接信息中的端口为该用户专属端口 |

失败响应 MUST 使用稳定文案并保持字段级定位：

| 情况 | 状态码 | 文案要点 |
|---|---|---|
| 指定端口超出端口池 | 422 | 指出允许范围 |
| 指定端口已被其他用户占用 | 409 | 提示更换端口 |
| 端口池已耗尽 | 409 | 提示扩大端口池的位置 |
| 端口被面板外进程占用 | 保存成功但待同步 | 详情页显示可理解原因并允许更换端口 |

## 仪表盘

新增端口池使用情况：已分配数、池容量、剩余可分配数（FR-035）。Xray 重启导致全部入站待重建时，
仪表盘与用户列表 MUST 把受影响用户显示为暂时不可用，MUST NOT 显示为已启用（FR-028、US5 场景 2）。

## 安全

端口与入站标签可以展示与审计；服务端密钥、用户密钥和完整连接信息仍 MUST 仅在已认证会话中出现，
且响应保持 `no-store`。审计摘要 MAY 含端口，MUST NOT 含任何密钥。
