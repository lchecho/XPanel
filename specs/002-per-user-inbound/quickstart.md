# Quickstart: 每用户专属入站的验证指南

**Feature**: `002-per-user-inbound` | **Date**: 2026-09-06

本指南给出可运行的端到端验证路径，用于证明每用户专属入站按规格工作。字段定义见
[data-model.md](data-model.md)，接口语义见 [contracts/](contracts/)。

## 1. 前置条件

- Go `1.26.8`（`GOTOOLCHAIN=auto` 会自动获取）。
- 固定版本 Xray `v26.3.27`。若主机没有官方二进制：

  ```sh
  GOBIN=$PWD/bin go install github.com/xtls/xray-core/main@v1.260327.0 && mv bin/main bin/xray
  bin/xray version   # 期望 Xray 26.3.27
  ```

- Xray 基础配置必须满足 [contracts/config.md](contracts/config.md)：`api.tag` 非空、`stats` 开启、
  `policy.levels."0".statsUserUplink/statsUserDownlink` 为 `true`。**不需要**预配置任何 SS2022 入站。
- 防火墙放行计划使用的端口池区间。

## 2. 构建与门禁

```sh
make build
make test                                                     # fake Xray 全量
XRAY_BIN=/path/to/xray XPANEL_REQUIRE_CONTRACT=1 make check    # 含真实 Xray 契约门禁
```

`make check` 通过是本功能的合并前置条件。契约套件必须覆盖
[contracts/xray-adapter.md](contracts/xray-adapter.md) 的 10 项兼容性门禁。

## 3. 人工验收路径

### 3.1 登记入站模板并创建首个用户（US1 / SC-001）

1. `bin/xpanel admin init` 初始化管理员，`bin/xpanel serve` 启动面板并登录。
2. 登记入站模板：填写公开主机名、监听地址、端口池区间、加密方式与网络能力。页面不应要求输入
   服务端密钥。模板校验通过后状态为“兼容”。
3. 创建用户，端口留空。期望：面板分配池内端口，详情页先显示“启用中（待同步）”，数秒后转为
   已启用并显示端口、入站标签与“监听中”。
4. 复制连接信息，用真实客户端连接该端口并产生 TCP 与 UDP 流量。期望：连接成功，详情页在 10 秒内
   显示上下行用量（SC-003）。

**计时**：从首次登录到复制出连接信息应在 5 分钟内完成（SC-001）。

### 3.2 端口分配与冲突（SC-013）

| 操作 | 期望 |
|---|---|
| 创建时指定池内空闲端口 | 使用该端口成功创建 |
| 指定已被其他用户占用的端口 | 创建前 409 拒绝，无部分状态 |
| 指定池外端口 | 422 拒绝并提示允许范围 |
| 端口池占满后再创建 | 拒绝并提示扩大端口池 |
| 先用其他进程占住某端口，再指定该端口 | 保存成功但待同步，详情页显示可理解原因，可更换端口后收敛 |

### 3.3 隔离性（SC-012）

创建两个用户 A、B 并都建立连接。对 A 依次执行禁用、启用、凭证轮换、删除，每一步检查：

- A 的端口按预期停止或恢复监听；轮换时 A 的端口**不中断**。
- B 的端口全程可连接，B 的用量计数不受影响。

### 3.4 配额闭环（US2 / SC-004 / SC-005）

给 A 设置小额配额并产生足够流量。期望：达到阈值后 10 秒内 A 的端口停止接受新连接，
详情页显示配额超限；B 不受影响。推进到下一个配额周期，期望 A 以**原端口**恢复监听（60 秒内）。

### 3.5 重启恢复（US5 / SC-006）

保持一个启用用户、一个手动禁用用户、一个配额超限用户，然后重启 Xray。期望：

- 重启后立刻查看，全部用户端口不可连接，页面显示暂时不可用而非已启用。
- 60 秒内启用用户以原端口恢复监听；禁用与超限用户的端口保持关闭。
- 全程未产生重复入站或重复端口占用。

### 3.6 漂移清理（SC-014）

用外部工具在面板命名空间前缀下手工创建一条入站，并另外保留一条运维自有入站。执行一轮协调后期望：
命名空间内的孤立入站被移除且端口释放并写入审计；运维自有入站保持不变。

## 4. 记录结果

把 SC-001、SC-002、SC-010 的人工计时与成功率，以及 3.2–3.6 的观察结果写入本功能的
`validation-report.md`（由实现阶段创建），格式参照 001 的同名文件。
